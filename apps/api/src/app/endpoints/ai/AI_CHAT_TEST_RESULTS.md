# AI Chat test results

Results are generated by the test run and written to **[AI_CHAT_TEST_RESULTS_10.md](./AI_CHAT_TEST_RESULTS_10.md)**.

**To run tests and refresh the report:**

```bash
# From repo root (full run; tests 4–10 need OPENAI_API_KEY in .env)
npm run test:ai-chat:report

# Quick run (Config + Input only, 3 tests, no API key)
QUICK=1 npm run test:ai-chat:report
```

See `AI_CHAT_TEST_RESULTS_10.md` for status, per-test results, and errors.
